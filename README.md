# capraecapital.com — independent static copy

Snapshot of the live site taken 2026-09-23 from the production web root
`/home/ubuntu/caprae-site/caprae-capital-services` (served by nginx as `capraecapital.com`).

## What's inside

    src/                      source for the main site pages (not served)
      template.html           layout, copy, styles and scripts for every main page
      build_pages.py          URL + meta table; writes the pages below and sitemap.xml
    site/                     the entire web root — this IS the website
      index.html              home                          ┐
      services/               /services/ + one folder per   │ GENERATED by
                              service (search-as-a-service, │ src/build_pages.py,
                              branding, ai-readiness, …)    │ do not edit by hand
      how-it-works/ results/ pricing/ contact/              ┘
      privacy/  terms/        legal pages
      field-notes/            blog index + posts + rss.xml
      assets/                 images, logos, portfolio, team, testimonials, legal.css
      404.html  robots.txt  sitemap.xml
      scripts/                python helpers used to build the legal pages (not needed to run)
    deploy/
      nginx-dev-caprae.saasquatchleads.com.conf   nginx config for the dev mirror

No backend, no database. Pure static HTML/CSS/images.

## Editing the main pages

Each nav item is its own URL with its own title, description, canonical and
social tags. All of them are generated from one template, so a change to the
nav, footer or styles lands on every page at once.

1. Edit `src/template.html` (content, styles, scripts) and/or the `PAGES`
   table in `src/build_pages.py` (URLs, meta titles, meta descriptions).
2. Run `python src/build_pages.py` (standard library only, Python 3.8+).
3. Commit both the source and the regenerated `site/` files.

Do not edit `site/index.html`, `site/services/**` etc. directly — the next
build overwrites them. Legacy `/#pricing`-style links still work: the home
page forwards them to the matching URL.

## Run it locally

Do NOT double-click index.html. All links and asset paths are root-relative
(`/assets/...`, `/pricing/`) and only resolve when served from a web root.

    cd site
    python3 -m http.server 8000

Then open http://localhost:8000

Any static server works equally well (`npx serve`, `php -S`, VS Code Live Server, etc.).

## Deploy it somewhere real

Drop the contents of `site/` into any static host — nginx, Apache, Netlify,
Vercel, Cloudflare Pages, S3 + CloudFront. Point the web root at `site/`.

This repo is served at **dev-caprae.saasquatchleads.com** by
`deploy/nginx-dev-caprae.saasquatchleads.com.conf` (web root
`/home/ubuntu/dev-caprae-site/site`; copy it to
`/etc/nginx/sites-available/`, then `sudo nginx -t && sudo systemctl reload nginx`).
That file holds things that are NOT in the site folder and would otherwise be lost:

- ~20 301 redirects for legacy URLs Google still has indexed
  (`/book`, `/team`, `/careers`, `/post/*`, …), plus slash-less page URLs
  (`/pricing` → `/pricing/`)
- the `404.html` error-page mapping
- cache headers for `/assets/` (30 days) and the security headers
- dev-only: `noindex` on every response, a `Disallow: /` robots.txt, and
  404s for `sitemap.xml` and the Google verification file
- Certbot SSL block

Canonical, Open Graph and sitemap URLs in the pages deliberately point at
`https://capraecapital.com` (`SITE_URL` in `src/build_pages.py`), the
production home of this content — the dev mirror is noindexed, so nothing
here competes with it in search.

## Notes / gotchas

- **Needs internet to look right.** Google Fonts, Termly (cookie consent),
  Google Tag Manager, and YouTube embeds load from remote hosts. Offline it
  still renders, just with fallback fonts and no consent banner.
- **Analytics and consent are wired to the original property.** Before putting
  this on a new domain, replace the Google Tag Manager container ID and the
  Termly IDs in `index.html`, or strip them.
- **`googled90b83ade46def6e.html`** is a Google Search Console verification file
  for the original domain. Delete it on a new domain.
- **Absolute links stay pointed at the original sites.** `index.html` links out
  to `capraecapitalpartners.com` and `capraecapitalpartners.substack.com`, and a
  handful of canonical/OG tags hardcode `https://capraecapital.com`. Update those
  if this copy becomes the canonical site.
- **Git history starts at this copy.** The original `.git` repo lives one level
  up in `caprae-site/` on the production server and covers the corporate site
  too, so it was left out; this folder has its own repo from the snapshot on.
- Stale `index.html.bak.*` backups were excluded.
